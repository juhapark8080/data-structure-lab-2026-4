# 보고서 작성용 초안

## 최종 프로젝트 프로그램 설명

본 프로젝트는 그래프 자료구조를 활용한 Qt/C++ 기반 항공권 조회 및 예매 GUI 프로그램이다. 서버와 데이터베이스는 구현하지 않고, 항공편 정보를 코드 내부에 고정 데이터로 저장했다. 사용자는 출발지와 도착지를 선택한 뒤 직항 항공편, 최저가 경로, 최단 시간 경로를 조회할 수 있으며, 원하는 항공편을 선택하면 예매 완료 메시지가 출력된다.

## 프로그램 동작 설명

1. 프로그램 실행 시 메인 창에 지도 영역, 출발지/도착지 선택 박스, 항공편 목록 테이블이 표시된다.
2. 사용자는 출발지와 도착지를 선택한다.
3. Search Direct Flights 버튼을 누르면 두 공항 사이의 직항 항공편이 표시된다.
4. Cheapest Route 버튼을 누르면 가격을 가중치로 사용한 최저가 경로가 표시된다.
5. Fastest Route 버튼을 누르면 시간을 가중치로 사용한 최단 시간 경로가 표시된다.
6. 항공편을 선택한 뒤 Book Selected Flight 버튼을 누르면 예매 완료 메시지가 출력된다.

## 왜 그래프 자료구조에 적합한 데이터인지?

항공 예매 데이터는 공항과 항공편 사이의 연결 관계로 구성된다. 각 공항은 그래프의 노드로 표현할 수 있고, 공항 사이를 이동하는 항공편은 간선으로 표현할 수 있다. 또한 항공편마다 가격과 소요 시간이 존재하므로 가중치 그래프로 모델링하기 적합하다. 출발지에서 도착지까지 직항뿐 아니라 환승 경로도 존재할 수 있기 때문에, 최저가 경로와 최단 시간 경로를 탐색하는 그래프 알고리즘을 적용할 수 있다.

## 최종 프로젝트 코드 설명

- `Flight` 구조체는 출발지, 도착지, 항공사, 가격, 소요 시간을 저장한다.
- `FlightGraph` 클래스는 항공편 데이터를 인접 리스트 방식으로 저장한다.
- `FlightGraph::dijkstra` 함수는 가격 또는 시간을 가중치로 선택하여 최적 경로를 찾는다.
- `MapWidget` 클래스는 공항 노드와 항공편 연결 관계를 화면에 그린다.
- `MainWindow` 클래스는 Qt 위젯, 버튼 이벤트, 항공편 목록 출력, 예매 완료 메시지를 관리한다.

## 객체지향 구조 설명

프로그램은 역할에 따라 클래스를 분리했다. `FlightGraph`는 데이터 저장과 그래프 탐색을 담당하고, `MapWidget`은 시각적 지도 표현을 담당하며, `MainWindow`는 사용자 입력과 화면 구성을 담당한다. 이렇게 분리하면 그래프 알고리즘과 GUI 코드가 섞이지 않아 유지보수가 쉽고, 각 클래스의 책임이 명확해진다.

## GUI 앱 구조 설명

GUI는 `QMainWindow`를 기반으로 구성했다. 상단에는 출발지와 도착지를 선택하는 `QComboBox`와 조회 버튼을 배치했다. 왼쪽에는 `MapWidget`을 이용해 공항 노드와 항공편 연결선을 표시하고, 오른쪽에는 `QTableWidget`으로 항공편 목록을 표시한다. 하단 설명 영역에는 검색 결과와 전체 가격/시간 정보를 출력하며, 예매 버튼을 누르면 `QMessageBox`로 예매 완료 메시지를 보여준다.
